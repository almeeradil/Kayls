# Kayls Fried Chicken - Online Ordering & Admin System 🍗

Kayls Fried Chicken (Jaranwala) online food ordering web application, built with modern web technologies, featuring a real-time admin panel and instant order notification alerts.

---

## 🚀 Features

* **Online Menu & Ordering:** Customers can browse menu items, view prices in PKR (Rs.), and place orders seamlessly.
* **Real-Time Admin Dashboard:** Live order tracking and notifications for incoming customer orders.
* **Admin Authentication:** Secure login for store managers (`admin@gmail.com` / `adminadmin`).
* **Sound Alerts:** Instant audio alerts on the admin PC whenever a new order is placed.

---

## 🛠️ Tech Stack

* **Frontend:** Next.js, React, HTML5, CSS3, JavaScript
* **Backend:** Node.js, Express (or Next.js API Routes)
* **Real-Time Comm:** Socket.io / WebSockets
* **Styling:** Emotion / Custom CSS
